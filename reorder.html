Checking stock, production plan and Yooz POs…
This can take up to a minute the first time.
How does it work? (short version)
  • What we have: the live inventory + the POs already on the way: Yooz, John's planner and Eleni's PO Tracker (received POs stop counting; open ones use her estimated delivery day).
  • What day the boxes are used: the working day before the Inv Date (production runs a day ahead — confirmed with Juan), or the production Day if the order has one.
  • What we will use: today's production plan, day by day. After the plan ends, what we usually use.
  • Covered until = the last day we have enough.
  • Safety stock = a cushion so a late truck or an extra run doesn't stop the line, in days of use: by default A 2 · B 1 · C 1 (A = most used, like BX1850 and BX1000). Sonic and PCA deliver next day (even same day), so their cushion is 1 day at most — about what John keeps. You can change it in ⚙️ Settings (PIN).
  • Supplier = the one we order from the most in the last 3 months. A rush PO uses the quickest one.
  • When to order: the supplier's usual delivery time before the day we would dip into the cushion. Orders go on the Friday before; each delivery is set for the day it's needed, never on Monday (moved to the Friday before, or Tuesday). Friday can take bigger deliveries.
  • How much: always full pallets, the way the supplier ships it (e.g. BX1850 = 750, two pallets double stacked).
  • Rush only when we would run out before a normal order can arrive.
  • 📝 We ordered…: write what was really ordered (quantity and day). It counts as coming everywhere, and the card shows what is still missing if the plan changed later.
  • Each PO has a status, the same on every device (PIN): Not ordered · ⏳ Pending (someone is on it, e.g. waiting for the supplier) · ✅ Created (made in Yooz, so nobody orders it twice). ✏️ Qty changes the amount; the next POs adjust. The first 2 POs show; tap “Show more” for the ones ahead.
  • 📅 Receiving days and holidays are the same for every device (PIN). ⬇ Excel downloads the list to share; 🖨 Print gives a big, clear list by order day (or Save as PDF).
  • Eleni's PO Tracker: a PO with a received date no longer counts as coming; an open one uses her estimated day. The morning count rules: a PO that was due yesterday or before is assumed to be already in the count, so it is not counted again. It stays listed on its item (⏳) so it isn't lost. 🏭 Suppliers shows real days, on-time and shorts per supplier.
  • It's a guide, not the PO: the official PO is still made in Yooz.
