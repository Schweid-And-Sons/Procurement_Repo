This can take up to a minute the first time.
How does it work? (short version)
  • What we have: the live inventory + the POs already on the way (Yooz and John's planner, each on its delivery day).
  • What we will use: today's production plan, day by day. After the plan ends, what we usually use.
  • Covered until = the last day we have enough.
  • Safety stock = a cushion so a late truck or an extra run doesn't stop the line. Bigger for A items (the most used, like BX1850 and BX1000), smaller for C items (little use, so they don't fill the racks).
  • When to order: the supplier's usual delivery time before the day we would dip into the cushion. Orders go on the Friday before; each delivery is set for the day it's needed.
  • How much: always full pallets, the way the supplier ships it (e.g. BX1850 = 750, two pallets double stacked).
  • Rush only when we would run out before a normal order can arrive.
  • It's a guide, not the PO: the official PO is still made in Yooz.
